# OBJETIVOS DEL SISTEMA
Desarollar una apliación interactiva en la consula, que simule un uego clásico como el de "Piedra, Papel o Tijera". 
Permitiendo así al usuario enfrentarse en un número indefinido de rondas contra la computadora de manera automatizada. El sistema busca aplicar la lógica del uso de estructuras de control y la generación de valores aleatorios para recrear una experiencia de juego continua con el conteo de puntuación. 

# DESCRIPCION DE FUNCIONALIDADES
- Menu interactivo: En este se permite al usuario ingresar su elección mediante números.
- Eleccion automatizada: La computadora seleccion al azar su jugada utilizando la libreria RANDOM.
- Evaluación de reglas: El sistema compara las elecciones y determina si hay empate, victoria del usuario o derrota de forma automatizada.
- Registro de puntuaciones: Se lleva un conteo acumulativo de los puntos obtenidos por parte del usuario y la computadora durante la sesión de juego.
- Rejugabilidad: Al finalizar cada ronda, se permite al usuario decidir si continua el jeugo o lo cierra.
